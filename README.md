## 2. 🗺️ Street Map – OpenStreetMap (OSM) Integration  
This project integrates **OpenStreetMap (OSM)** into an application, providing a **real-time, interactive map** for location visualization, route planning, and tracking purposes.  

#### ✨ Features  
- 🗺️ **Interactive Map**: Displays a fully functional map using OpenStreetMap.  
- 📍 **Shapes Plotted in Map**: Plot Diff Shapes to Seperate it , on different scenarios .  
- 🛣️ **Shape Management**: Plot and visualize coordinates That auto fit zoom.  

#### 🛠️ Technologies Used  
- **Frontend**: HTML, CSS, JavaScript  
- **Mapping API**: OpenStreetMap
